# Full Page PNG

Локальное расширение для Google Chrome: снимает всю текущую веб-страницу и сразу сохраняет её в PNG — без редактора, отдельной вкладки и диалога выбора файла.

## Установка

1. Откройте в Chrome адрес `chrome://extensions`.
2. Включите **Режим разработчика** справа вверху.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку расширения, содержащую файл `manifest.json`.
5. При желании закрепите **Full Page PNG** на панели Chrome.

## Использование

- Нажмите значок расширения; или
- нажмите `Alt + Shift + P` на Windows или `⌥ ⇧ P` на Mac.

Синий значок `…` означает, что снимок создаётся. Зелёная галочка означает, что загрузка PNG началась. Красный `!` означает ошибку; наведите курсор на значок расширения, чтобы увидеть пояснение.

Горячую клавишу можно изменить на странице `chrome://extensions/shortcuts`.

Файл получает имя вида:

`example.com - 2026-08-11_11-55-00.png`

## Качество и сохранение

- Формат — PNG без потерь.
- Расширение сначала снимает страницу в полном нативном разрешении Chrome/Retina без уменьшения.
- Если страница настолько велика, что Chrome не может создать одно изображение, расширение последовательно пробует 75%, 50% и 25% и выбирает первый рабочий вариант.
- Для защиты браузера от чрезмерного расхода памяти расширение не запускает захват, если даже при масштабе 25% итоговый PNG превышал бы безопасные пределы.
- Снимок автоматически сохраняется в стандартную папку загрузок Chrome.

Chrome не позволяет обычному расширению задавать абсолютный путь на диске. Нужную папку можно выбрать на странице `chrome://settings/downloads`.

## Ограничения Chrome

- Работает на обычных `http://`, `https://` и разрешённых `file://` страницах.
- Не работает на `chrome://`, в Chrome Web Store и на других служебных страницах браузера.
- Перед снимком расширение быстро прокручивает страницу, чтобы загрузились отложенные изображения, а после возвращает исходную позицию.
- DevTools для снимаемой вкладки должны быть закрыты.
- Во время создания снимка Chrome может ненадолго показать сообщение о подключённом отладчике. Это штатное уведомление: расширение использует тот же протокол захвата страницы, что и DevTools, и сразу отключается после снимка.

Все действия происходят локально. Расширение ничего не отправляет в интернет.

## Безопасность и разрешения

- Расширение не содержит стороннего кода, аналитики и сетевых обращений.
- Разрешение `activeTab` даёт временный доступ только к открытой вкладке после явного запуска пользователем.
- Разрешение `debugger` необходимо для штатной команды Chrome, снимающей страницу целиком; подключение действует только во время создания снимка и закрывается даже при ошибке.
- Разрешение `downloads` используется только для сохранения готового PNG в папку загрузок Chrome.
- Расширение не читает и не изменяет остальные файлы компьютера, настройки браузера, историю, cookies, пароли и данные других вкладок.

## Совместимость

- Поддерживается Google Chrome 116 и новее на Windows 11 и macOS.
- В Windows имя файла не содержит запрещённых символов, а сохранение выполняется через стандартный менеджер загрузок Chrome.
